# Mora v0.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver Mora 0.3.0 with a subtle draggable reading-position thumb, English/Chinese UI, separated app settings, selectable launcher icons, pure-black dark surfaces, predictive back, and a fully gated stable release.

**Architecture:** Keep Mora’s existing single-activity, local-first structure. Add small typed settings and launcher components, keep reader geometry pure and WebView interaction native, and layer the existing Home below Document for predictive back instead of adding a navigation framework. Android resources own UI language; user Markdown remains untouched.

**Tech Stack:** Kotlin 2.3, Jetpack Compose Material 3, AndroidX Activity Compose, WebView, Android resources/LocaleConfig, SharedPreferences, Gradle 9.5/AGP 9.3, JUnit 4, GitHub Actions.

- [ ] **Step 5: Collect predictive progress safely**

```kotlin
try {

        onProgress(event.progress, event.swipeEdge)
    }
    onCompleted()
} catch (cancelled: CancellationException) {
    onCancelled()
}
```

Reset on disposal, never close on cancellation, freeze eligibility during an active
gesture, and keep system bars visible until the cancellation rebound finishes.
