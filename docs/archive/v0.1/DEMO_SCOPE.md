# Demo 范围

## 本轮目标

验证以下产品判断：

- Material You 外壳与文档正文可以明确分工
- 阅读与编辑两种模式足以构成第一版核心闭环
- 阅读页采用 HTML/CSS 能做出明显优于传统 Android Markdown 控件的排版
- 编辑页先验证手机输入与快捷栏，再替换为 CodeMirror 6
- 标准 Markdown 文件和 Android 系统文件选择器可以作为数据基础

## 验收路径

```text
首页
  ↓
打开示例 / 打开本地文件 / 新建文档
  ↓
阅读模式
  ↓
编辑模式 + Markdown 快捷栏
  ↓
回到阅读查看结果
  ↓
保存或另存为
```

## 不属于本轮

- 知识库
- 双链与图谱
- 标签数据库
- 云同步
- 完整文件夹管理
- Typora 式行内所见即所得
- 插件系统
